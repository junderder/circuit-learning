# 电路学堂 · Circuit Lab

面向「电气工程及其自动化」专业《电路》课程的自学网站。纯静态页面，**无需安装、无需联网、双击即用**。

## 打开方式

双击 `index.html` 即可（推荐 Chrome / Edge / Firefox 新版）。所有页面、样式、脚本、图表都在本地运行。

> 学习进度、错题本、自测成绩保存在浏览器本地（localStorage），换浏览器或清除浏览数据会丢失。页脚有「清除本地进度」入口。

## 功能

| 页面 | 说明 |
| --- | --- |

| `chapter.html?id=xxx` | 章节正文：学习目标、分节讲解、核心公式、典型例题（可折叠解答）、易错点清单、本页目录与阅读进度条 |

| `formulas.html` | 78 条公式速查，支持搜索，可打印为 PDF |

### 交互工具

1. **分压 / 分流**：串联电压源与并联电流源两种模式，实时给出各量、比例条与公式。
2. **RC / RL 响应**：拖动 R、C（或 L）与时间游标，观察一阶响应曲线、τ、63.2% 点。
3. **RLC 与谐振**：阻抗—频率曲线、相量图、谐振频率、Q 值与通频带联动。
4. **三相电路**：Y/Δ 切换，线值相值、功率、波形实时计算。
5. **色环电阻**：4 环 / 5 环，选颜色即出阻值与误差范围。
6. **最大功率**：负载功率曲线与匹配点，实时显示效率。

## 扩展内容

**加一道题**：在 `js/quiz-a.js` 或 `quiz-b.js` 里追加

```js
{ id: 'q3-8', ch: 'kcl-kvl', level: 2,
  q: '题干（可用 <sub> 等 HTML）',
  options: ['A', 'B', 'C', 'D'], answer: 1,
  explain: '解析：为什么选 B。' }
```

`ch` 取章节的 `id`，`level` 为 1/2/3（基础/进阶/综合）。题目会自动出现在分章练习、随机综合、公式页统计里。

**加一章**：在对应的 `content-*.js` 中向 `D.chapters` push 一个对象（字段参考现有章节：`id`、`num`、`title`、`module`、`minutes`、`summary`、`keywords`、`objectives`、`sections`、`formulas`、`examples`、`mistakes`）。新章节会自动出现在目录、进度统计、公式速查中。

**加一条推导**：在 `js/derive-data.js` 的数组里追加

```js
{
  id: 'kvl-loop', ch: 'kcl-kvl',      // ch 必须是已有章节的 id
  title: '回路电流法',
  subtitle: '一句话说明这条推导想回答什么',
  steps: [
    { eq: 'Σu = 0', note: '第一步在做什么' },
    { eq: 'R<sub>1</sub>i + ' + M('R<sub>2</sub>i'), note: '用 M() 包住的关键项会扫过高亮' }
  ]
}
```

`M(x)` 生成 `<mark>`，`F(a,b)` 生成上下分数，`SQ(x)` 生成根号（三个小工具定义在文件顶部）。章节页与推导页都会自动收录，无需改其他地方。

**改主题色**：`css/style.css` 顶部的 `:root` 与 `html[data-theme="dark"]` 中的 CSS 变量。

## 技术说明

- 零依赖、零构建：原生 HTML/CSS/JavaScript，图表用 Canvas 手绘，公式用 HTML + CSS 排版（无 KaTeX/MathJax）。
- 响应式：桌面三栏 / 平板两栏 / 手机单栏；已按 390px 宽度验证无横向溢出。
- 可访问性：语义化标签、跳转链接、`aria-current`/`aria-selected`、键盘可达、`prefers-reduced-motion` 与 `prefers-color-scheme` 适配。
- 打印：章节页与公式页均提供打印样式（隐藏导航，避免卡片被截断），可另存为 PDF。
- 主题：右上角按钮切换亮/暗；也可用 `?theme=light` / `?theme=dark` 强制指定。
